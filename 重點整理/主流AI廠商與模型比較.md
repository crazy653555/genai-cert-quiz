# 主流AI廠商與模型比較

| 廠商 | 模型系列 | 特色、定位與考點說明 |
|---|---|---|
| OpenAI | GPT 3.5 / 4 / 5 | 一組可理解與生成文字/程式的大語言模型（GPT-3.5達175B參數）；GPT-4/5具多模態與工具調用能力。 |
| OpenAI | GPT Thinking 系列 | 花更多時間進行鏈式思考，擅長推理、科學、數學與困難程式問題。 |
| OpenAI | DALL-E / Whisper / Embeddings | 分別用於圖像生成/編輯、語音轉文字（TTS/ASR），以及文本向量化。 |
| Google | Gemini 2.5 / 3 系列 | Pro版本擅長複雜任務理解；Flash版本適合日常高效能任務。 |
| Anthropic | Claude 3.5 系列 | 由前OpenAI團隊創立，性能卓越，邏輯嚴密，受企業歡迎。 |
| Meta | Llama 2 / 3 / 4 系列 | 主流開源大模型，提供免費商用授權，包含7B、13B、70B等版本，最小可在28GB記憶體上執行。 |
| Mistral AI | Mistral 系列 | 採用混合專家模型（MoE，如8x7B），以較低成本獲得媲美高參數量模型的性能。 |
| DeepSeek | DeepSeek R1 | 開源推理模型代表，展示利用強化學習（RL）驅動推理過程，執行效率極高。 |
| Alibaba | Qwen 2 / 3 系列 | 通義千問，經海量預訓練，提供多尺寸且全球受歡迎的開源模型生態。 |
| xAI | Grok 4 系列 | Elon Musk旗下公司研發，具備超大規模GPU算力集群，評測效能突出。 |

> ⚠️ 爭議備註：上表模型版本號、參數量為原始筆記提供的資訊，AI廠商模型迭代速度快，考前建議對照各廠商官網確認目前最新版本號是否已更新（例如GPT、Gemini、Claude、Llama、Grok等系列皆持續在推出新版本）。
