# Prompt工程與提示技巧

## 推理類提示技巧

- **Chain-of-Thought（CoT，思路鏈）**：幫助模型透過「多步推理」解決複雜問題；準確性確保方式是在生成最終答案前，**檢查和生成每一個中間步驟**。
- **Tree-of-Thought（ToT，思考樹）**：有助於分解複雜問題、促進逐步思考、提高解決問題準確性（非單一步驟解答）。
- **Few-Shot Prompting（少樣本提示）**：最常用於需要模型理解並根據**範例**進行生成的任務。

## 生成控制參數

- **溫度參數（Temperature）**：用於控制生成文本的多樣性與創造力，透過改變生成過程中的隨機性（預測詞語的機率分布）來調整。

## Prompt 設計最佳實踐

- **激發創造力**：使用開放式的指令和範例。
- **控制語氣**：提供符合語氣的範例和明確的指令。
- **長度與結構**：Prompt長度需足夠長以適當表達需求；多步驟Prompt使用**列表或編號**能使其更清晰。
- **符號作用**：使用 `{}` 大括號可用於區隔關鍵資訊（如輸入文本或變數）。
- **結果不符期待時**：應指出錯誤並給予更具體指令、提供更多背景上下文，**不應**把指令直接改為模糊的開放性問題。
- **常見誤解**：單純「訓練更大的AI模型」並不能直接提升使用者端撰寫Prompt的技巧——Prompt能力是使用者技能，不是模型規模問題。
