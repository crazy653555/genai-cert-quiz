# 模型架構與核心技術

## AI 技術階層架構

```
人工智慧 (Artificial Intelligence, AI)
│
├─ 機器學習 (Machine Learning, ML)
│    學習範式：監督式學習 / 非監督式學習 / 強化學習
│
│    └─ 深度學習 (Deep Learning, DL)
│         基於多層類神經網路，是現代生成式AI的技術基礎
│
│         └─ 類神經網路 (Neural Network, NN)
│              最小單元：感知機 (Perceptron)
│
│              ├─ MLP 多層感知機 (Multilayer Perceptron)
│              │    最基礎的前饋神經網路，由「輸入層→隱藏層→輸出層」組成，
│              │    各層間全連接，是其他進階架構的理論基礎
│              │
│              ├─ CNN 卷積神經網路 (Convolutional Neural Network)
│              │    擅長影像特徵擷取與辨識，主要為「判別式」用途；
│              │    圖片生成中的「神經風格轉換 (Neural Style Transfer)」技術也基於CNN架構
│              │
│              ├─ RNN 循環神經網路 (Recurrent Neural Network)
│              │    處理具時間/順序性的資料（文字、語音）
│              │    │
│              │    └─ LSTM 長短期記憶模型 (Long Short-Term Memory)
│              │         RNN的改良版，解決梯度消失問題，具「長期依賴關係」處理能力，
│              │         常用於歌聲合成、音樂序列生成
│              │
│              ├─ Transformer（變換器）
│              │    核心貢獻：導入注意力機制 (Attention Mechanism)，尤其是自注意力機制 (Self-Attention)；
│              │    GPT系列主要採用多頭注意力機制 (Multi-Head Attention)
│              │    是現代LLM（大型語言模型）的骨幹架構
│              │
│              ├─ GAN 生成式對抗網路 (Generative Adversarial Network)
│              │    由「生成器 (Generator)」與「鑑別器 (Discriminator)」兩個網路組成，彼此互相競爭
│              │    - 生成器：產生與訓練資料集極為相似的新資料（主要應用於圖片生成）
│              │    - 鑑別器：負責判斷資料真偽，驅動生成器持續進步（動態博弈）
│              │    代表作：StyleGAN（NVIDIA開發，以從隨機雜訊產生逼真圖片聞名）
│              │
│              ├─ Autoencoder 自動編碼器
│              │    學習資料的壓縮表徵（Encoding）再還原（Decoding），可用於特徵學習
│              │
│              └─ DBN 深度信念網路 (Deep Belief Network)
│                   由多層受限波茲曼機堆疊而成的生成式模型
│
└─ 延伸應用型架構（建立在上述基礎之上）
     ├─ RAG 檢索增強生成 (Retrieval-Augmented Generation)
     │    在LLM生成回答前，先從外部知識庫檢索資訊，提供最新且正確的內容
     │    優勢：降低幻覺機率、成本較低、可即時更新知識
     ├─ LMM 大型多模態模型 (Large Multimodal Model)
     │    整合處理文字、圖片、音訊等多種資料型態
     └─ Diffusion Model 擴散模型
          主流文生圖技術之一（如Stable Diffusion），透過逐步去噪生成圖片
```

### 另一個分類軸：依「輸出目的」區分

```
AI系統
├─ 判別式 AI (Discriminative AI)
│    任務：分類、判斷、預測既有資料的標籤（如資料分類、標籤貼附）
│    代表：CNN分類器、傳統ML分類器(SVM等)
│
└─ 生成式 AI (Generative AI)
     任務：創造全新內容（文字/圖片/音訊/影片）
     代表：GAN、Transformer-based LLM、Diffusion Model
```

- 相較於判別式AI，生成式AI在追求更高層次的創意生成與邏輯推演時，面臨的主要資料挑戰是**缺乏具備豐富邏輯性與準確性的標記數據**。

## 基礎觀念釐清

- **AIGC運作基礎**：透過大量資料整合與分析，模擬人類的思考過程（注意：AI並不具有真正的自我意識與情感，亦非必然使用量子運算）。

## 核心技術名詞對照表

| 名詞 | 全稱／類別 | 核心特色與考試重點 |
|---|---|---|
| ML | Machine Learning | 機器學習，AI的子領域，透過資料訓練模型而非明確規則編程；分監督式/非監督式/強化學習三大範式。 |
| DL | Deep Learning | 深度學習，ML的子領域，使用多層類神經網路，是現代生成式AI的技術基礎。 |
| MLP | Multilayer Perceptron | 多層感知機，最基礎的前饋神經網路，由輸入層、隱藏層、輸出層組成，各層全連接。 |
| CNN | Convolutional Neural Network | 卷積神經網路，擅長影像特徵擷取與辨識的判別式模型；神經風格轉換技術也基於此架構。 |
| RNN | Recurrent Neural Network | 循環神經網路，擅長處理與生成具時間順序性的數據（文字、語音）。 |
| LSTM | Long Short-Term Memory | 長短期記憶網路，解決傳統RNN梯度消失問題，具備長期依賴處理能力。 |
| Transformer | 變換器模型架構 | 生成式AI的基石，核心貢獻為導入「自注意力機制」，為現代LLM骨幹架構。 |
| GAN | Generative Adversarial Network | 生成式對抗網路，生成器與鑑別器對抗博弈，專門用於產生高擬真圖像。 |
| Autoencoder | 自動編碼器 | 學習資料壓縮表徵再還原，可用於特徵學習與降維。 |
| DBN | Deep Belief Network | 深度信念網路，由多層受限波茲曼機堆疊而成的生成式模型。 |
| Diffusion Model | 擴散模型 | 主流文生圖技術之一（如Stable Diffusion），透過逐步去噪生成圖片。 |
| LMM | Large Multimodal Model | 大型多模態模型，整合處理文字、圖片、音訊等多種資料型態。 |
| RAG | Retrieval-Augmented Generation | 檢索增強生成，LLM生成前先檢索外部知識庫，降低幻覺並提供即時資訊。 |
| TensorFlow | 開源機器學習庫 | Google開發，核心特色為「資料圖運算」，支援CPU/GPU/TPU，廣泛用於模型訓練。 |
| CoT | Chain-of-Thought | 思路鏈提示，引導模型透過多步推理拆解複雜問題（詳見 [[Prompt工程與提示技巧]]）。 |
