# 模型架構與核心技術

## 生成式模型架構

- **GAN（生成式對抗網路，Generative Adversarial Network）**
  - 由「生成器（Generator）」與「鑑別器（Discriminator）」兩個網路組成，彼此互相競爭。
  - 目標：生成與訓練資料集極為相似的新資料（主要應用於圖片生成）。
  - 鑑別器負責判斷資料真偽；生成器與鑑別器處於動態博弈（互相拉扯進步）。
- **StyleGAN**：由 NVIDIA 開發，以能從隨機雜訊（Random Noise）產生逼真圖片聞名。
- **Transformer（變換器）**
  - 生成式AI的核心貢獻是**導入注意力機制（Attention Mechanism）**，尤其是**自注意力機制（Self-Attention）**。
  - GPT 模型主要採用**多頭注意力機制（Multi-Head Attention）**。
- **CNN（卷積神經網路）**：主要用於特徵識別與分類的「判別式模型」，而非從無到有產生影像的生成式框架；圖片生成中的「神經風格轉換（Neural Style Transfer）」技術主要基於CNN架構。
- **RNN 與 LSTM**
  - RNN（循環神經網路）：用於處理與生成順序數據（如文本、語音）。
  - LSTM（長短期記憶模型）：解決傳統RNN梯度消失問題，具備處理「長期依賴關係」的能力，常用於歌詞合成或音樂序列生成。
- **RAG（檢索增強生成，Retrieval-Augmented Generation）**
  - 在LLM生成回答前，先從外部知識庫檢索資訊，提供最新且正確的內容，大幅降低幻覺機率。
  - 優勢：降低幻覺、成本較低、可即時更新知識。
- **LMM（大型多模態模型，Large Multimodal Model）**：能整合與處理文字、圖片、音訊等多種資料型態。

## 基礎觀念釐清

- **AIGC運作基礎**：透過大量資料整合與分析，模擬人類的思考過程（注意：AI並不具有真正的自我意識與情感，亦非必然使用量子運算）。
- **判定式AI vs 生成式AI**：相較於傳統判定式AI，生成式AI在追求更高層次的創意生成與邏輯推進時，面臨的主要資料挑戰是**缺乏具備豐富邏輯屬性及準確性的標記數據**。

## 核心技術名詞對照表

| 名詞 | 全稱／類別 | 核心特色與考試重點 |
|---|---|---|
| TensorFlow | 開源機器學習庫 | Google開發，核心特色為「資料圖運算」，支援CPU/GPU/TPU，廣泛用於模型訓練。 |
| RNN | Recurrent Neural Network | 循環神經網路，擅長處理與生成具時間順序性的數據（文字、語音）。 |
| LMM | Large Multimodal Model | 大型多模態模型，整合處理文字、圖片、音訊等多種資料型態。 |
| Transformer | 變換器模型架構 | 生成式AI的基石，核心貢獻為導入「自注意力機制」。 |
| LSTM | Long Short-Term Memory | 長短期記憶網路，解決傳統RNN梯度消失問題，具備長期依賴處理能力。 |
| RAG | Retrieval-Augmented Generation | 檢索增強生成，LLM生成前先檢索外部知識庫，降低幻覺並提供即時資訊。 |
| CoT | Chain-of-Thought | 思路鏈提示，引導模型透過多步推理拆解複雜問題（詳見 [[Prompt工程與提示技巧]]）。 |
| GAN | Generative Adversarial Network | 生成式對抗網路，生成器與鑑別器對抗博弈，專門用於產生高擬真圖像。 |
