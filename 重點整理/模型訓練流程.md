# 模型訓練流程

## 整體三階段

1. **預訓練（Pre-training）**：模型從大量文字中學習語言的基本知識與模式。
2. **微調（Fine-tuning）**：針對特定任務或資料集進一步調整模型。
3. **RLHF（人類回饋強化學習）**：在前兩步之後，進一步讓模型學會「說得好」，不只是「會說話」。

## 訓練與資料處理核心觀念

- **損失函數（Loss Function）**：評估模型預測與真實值之間的差距/性能，數值越小代表預測越準確（參見 [[考試題目/題庫04]] 第48題的 Loss Function 詳解）。
- **過擬合（Overfitting）**：模型在**訓練資料上表現良好，但在測試資料上表現較差**的現象。
- **Garbage in, Garbage out（垃圾進，垃圾出）**：強調**訓練資料品質**對生成式AI模型表現的決定性影響。
- **訓練重點**：生成式AI訓練過程主要著重於**資料的多樣性**。
- **資料前處理關鍵步驟**：收集高品質的原始資料；缺失資料應進行資料清洗（Data Cleaning）。
- **資料視覺化原則**：為使設計簡潔明瞭，應避免資訊過多，並優先考慮圖表配色。
- **強化學習（Reinforcement Learning, RL）**：目標是透過與環境的交互學習來最大化累積獎勵；負責「知覺環境並做出反應」的要素稱為**代理（Agent）**。
- **常用開發工具**：機器學習模型訓練與資料圖運算常用 **TensorFlow**（Python開發環境）；開發AI簡報生成應用常用語言為 **Python**。

## RLHF（Reinforcement Learning from Human Feedback）

- 全名：**從人類回饋中學習的強化學習**。
- 是GPT-4、Claude、Gemini等大型語言模型共通的關鍵訓練技術。
- **目標**：讓AI不只會產生答案，而是產生「人類偏好、合人意」的答案。

### 運作方式

1. AI針對同一問題產生多個候選答案。
2. 由人類對這些答案進行**排序**，標示哪個較好。
3. 模型依排序結果調整自己的回答偏好，逐步學會「怎麼說話更合人意」。

> 比喻：訓練小孩說話不只是背字典，而是學習「怎麼說會讓人喜歡聽」。

### RLHF 與 Prompt 的差異

| 項目 | Prompt（提示） | RLHF |
|---|---|---|
| 性質 | 使用者對AI下達指令的方式 | 模型訓練階段的技術 |
| 作用對象 | 輸入端（使用者如何問） | 模型本身（AI如何學會回答偏好） |
| 比喻 | 你對AI說話的方式 | 讓AI學會「怎麼說話才合人心」的訓練秘訣 |

- 沒有RLHF：模型僅是「一本會自動說話的字典」（有知識但不一定合人意）。
- 有RLHF：模型更像「一位真正願意幫忙的對話夥伴」。

## 模型個性化方法——LoRA（微調的輕量化升級版）

- 問題背景：原始模型雖強大，但不一定適合特定場景；傳統「微調」能讓模型更懂需求，但**很貴、很慢**，需要大量算力與資料。
- **LoRA（Low-Rank Adaptation，低秩調整）**：不更新整個模型的所有參數，而是另外新增一小組「可調整的參數模組」，只訓練這些模組來微調模型表現。
- 比喻：
  1. 不用翻新整棟大樓（整個模型）；
  2. 只在某幾層關鍵樓層安裝活動式隔間，讓空間可依需求變動。
- 插入的模組非常小，訓練起來快又省錢，但效果能大幅改變模型行為。

### LoRA 的好處

1. **成本低**：只需訓練少量參數，比傳統微調更省資源。
2. **快速實作**：可針對不同任務，各自建立一套LoRA模組。
3. **容易切換**：像換配件一樣，不同任務切換不同LoRA模組即可，原始模型不變，不用每次重新訓練。

- LoRA跟提示工程不一樣：提示工程是透過「說話方式」引導AI產生不同回應；LoRA則是真的去調節新增小型模組裡的參數，屬於「輕量級微調」技術，當需要更多客製化控制時可使用。
- LoRA現已成為許多開源模型（如LLaMA、Mistral）微調的標準做法，是工程師用小筆預算打造專屬AI的常見選項。

### 微調、LoRA、提示工程 比較

| 項目 | 微調（Fine-tuning） | LoRA（Low-Rank Adaptation） | 提示工程（Prompting） |
|---|---|---|---|
| 原理 | 直接修改整個模型的參數 | 插入小型可訓練模組，只更新模組裡的極少量參數 | 改變「說法」來引導模型產生不同回應 |
| 是否改動模型本身 | 全面改動 | 局部增修參數（原始參數不動） | 完全不改動 |
| 資源需求 | 非常高，需大量算力與資料 | 中等，只需訓練輕量模組，成本低 | 最低，不需訓練 |
| 客製化程度 | 可打造專用模型，風格、知識皆可重塑 | 可定向調整模型行為，效果接近微調 | 限度內調整語氣、格式、回答方式 |
| 適合情境 | 大企業或專案需建專用模型 | 想客製化又希望保留原模型，可彈性重用 | 一般使用者、快速控制回應風格與結構 |
| 例子 | 建立法律、醫療、教育等專用LLM | 微調醫學報告或客服語氣，不改原始模型 | 「請用三歲小孩能懂的方式說明區塊鏈」|
