生成式AI能力認證 複習測驗網站
================================

使用方式
--------
直接用瀏覽器開啟 index.html 即可開始測驗（Chrome / Edge / Safari 皆可），
不需要安裝任何東西、不需要網路連線、不需要架設伺服器。
整份資料夾可以直接複製或壓縮傳給別人，對方一樣用瀏覽器打開 index.html 就能測驗。

資料夾內容
----------
- index.html   複習測驗網頁本體（題目資料已內嵌在網頁裡，離線可用）
- quiz.db      SQLite 資料庫備份（題庫原始資料，供日後維護/查詢用；網頁運作不需要它）
- README.txt   本說明檔

功能說明
--------
- 開始測驗前可選擇「考試來源」（可複選，依題庫批次 題庫01~題庫06）
- 可選擇「選項是否隨機排序」（開啟後每次出現同一題，A/B/C/D 的順序都會重新洗牌）
- 可選擇「排除有爭議備註的題目」
- 可勾選「限制本次出題數」，自訂本次只隨機抽考幾題（例如80題），抽選不重複
- 題目採整組洗牌，一輪內不會重複出現同一題，出完所選範圍的題目後會顯示測驗結果統計
- 答錯/答對都會顯示正確答案與完整解析；若該題有 ⚠️ 爭議備註也會一併顯示
- 測驗中可隨時按「結束測驗並看結果」提前中斷；不論是正常寫完還是中途結束，
  結果畫面都會把本次答錯的題目重新列出來，附上你當時選的答案、正確答案與解析，方便針對弱點複習

資料庫結構（quiz.db 的 questions 資料表）
--------------------------------------
id              題號（整數，主鍵）
source          來源批次（題庫01 ~ 題庫06）
topic           主題分類（基礎知識／能力強化／應用技能／倫理與法律／綜合）
question        題幹
option_a~d      四個選項文字
correct_option  正確答案（A/B/C/D）
explanation     解析
has_caveat      是否有爭議備註（0/1）
caveat_note     爭議備註內容

若題庫內容有更新
----------------
題庫原始檔在「考試題目/」資料夾（Markdown格式），更新後請依序重跑（兩支腳本會直接
把 quiz.db 和 index.html 寫進本資料夾，不需要再手動複製）：
  1. python _raw/build_db.py    重新產生 複習測驗網站/quiz.db
  2. python _raw/build_html.py  重新產生 複習測驗網站/index.html（把最新題目嵌入網頁）
